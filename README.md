# Service Provider Frontend

This is the **frontend** for the Capstone Project, built with **React 19**, **Vite 7**, and **TypeScript**.  
It uses **TailwindCSS**, **React Hook Form**, **Zod**, and **Axios** for UI and data handling.  

---

##  Tech Stack
- React 19
- Vite 7
- TypeScript 5
- TailwindCSS 4
- Radix UI
- React Router v7
- React Hook Form + Zod
- Axios
- ESLint + Prettier

---

- Node.js **v20.19.2**
